# Flor Árabe Perfumaria — UX/UI Specification

## Versão

v1.0

---

# Visão da Experiência

A Flor Árabe Perfumaria deve transmitir uma experiência premium, elegante e minimalista.

O usuário deve sentir que está navegando por uma boutique especializada em perfumes árabes, com foco em qualidade, exclusividade e atendimento personalizado.

A interface deve priorizar:

* Clareza
* Leveza visual
* Sofisticação
* Conversão rápida via WhatsApp

---

# Objetivo de UX

Permitir que um visitante:

1. Encontre rapidamente um perfume.
2. Visualize suas informações.
3. Entre em contato pelo WhatsApp.
4. Faça isso com o menor número possível de interações.

Meta:

Máximo de 2 cliques até iniciar a conversa no WhatsApp.

---

# Design Principles

## P1 — Minimalismo Elegante

A interface deve utilizar apenas os elementos necessários.

Todo elemento visual precisa ter uma função clara.

---

## P2 — Espaço em Branco

O espaço vazio é parte do design.

Evitar páginas densas ou visualmente carregadas.

---

## P3 — Produto em Destaque

O perfume é o protagonista.

Elementos decorativos nunca devem competir com as imagens dos produtos.

---

## P4 — Conversão Natural

O WhatsApp deve estar sempre acessível sem parecer agressivo.

---
